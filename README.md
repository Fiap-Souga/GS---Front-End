## Descrição do Projeto

Orbital Connect é uma Landing Page desenvolvida para apresentar uma solução tecnológica baseada em comunicação via satélites. O projeto tem como objetivo demonstrar como a tecnologia espacial pode ampliar o acesso à internet, monitoramento e comunicação em regiões remotas.

## Funcionalidades

* Menu de navegação entre seções
* Seção de apresentação do problema
* Seção de tecnologias utilizadas
* Seção de objetivos do projeto
* Seção de público-alvo
* Seção de benefícios
* Seção de aplicação no dia a dia
* Layout responsivo
* Uso de imagens e ícones
* Estilização moderna com CSS
* Utilização de Flexbox
* Variáveis CSS
* Google Fonts
* Reset CSS
